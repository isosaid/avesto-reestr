# Феҳристи ҷамъиятҳо · Авесто Гуруҳ

Веб-реестр юридических лиц холдинга: реестр как в Excel, выписки из ЕГР (PDF) по клику на дату, схема владения, проверки данных, журнал изменений.

- Фронтенд: статический сайт (этот репозиторий, GitHub Pages).
- Данные, вход и PDF: Supabase (таблицы `reg_*`, приватный бакет `reg-extracts`, RLS).
- Данные в репозитории **не хранятся** — только код. Без входа сайт ничего не показывает.

Настройка: `config.js` → `SUPABASE_URL` и `SUPABASE_ANON_KEY` (anon-ключ публичный по замыслу Supabase, доступ ограничен RLS).
